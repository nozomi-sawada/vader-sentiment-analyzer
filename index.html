このツールについて About This Tool

VADERについて About VADER

VADER (Valence Aware Dictionary and sEntiment Reasoner) は、ソーシャルメディアテキストの感情分析のために開発された辞書・ルールベースの感情分析手法です（Hutto & Gilbert, 2014）。本ツールはその本家Python実装（vaderSentiment 3.3.2）をブラウザ向けに移植したもので、出力が本家と一致することを自動テストで検証しています。 VADER (Valence Aware Dictionary and sEntiment Reasoner) is a lexicon and rule-based sentiment analysis method attuned to sentiments expressed in social media (Hutto & Gilbert, 2014). This tool is a browser port of the reference Python implementation (vaderSentiment 3.3.2), with automated tests verifying that its output matches the reference.
