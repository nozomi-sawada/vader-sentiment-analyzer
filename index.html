VADER準拠 感情分析ツール VADER-based Sentiment Analysis Tool

VADERは英語テキスト専用の感情分析システムです。エモーティコン（顔文字）や絵文字にも対応しています。 VADER is a sentiment analysis system designed for English text, supporting emoticons and emojis.

VADERについて About VADER

VADER (Valence Aware Dictionary and sEntiment Reasoner) は、ソーシャルメディアテキストの感情分析のために開発された辞書・ルールベースの感情分析手法です（Hutto & Gilbert, 2014）。本ツールはその本家Python実装（vaderSentiment 3.3.2）をブラウザ向けに移植したものです。 VADER (Valence Aware Dictionary and sEntiment Reasoner) is a lexicon and rule-based sentiment analysis method attuned to sentiments expressed in social media (Hutto & Gilbert, 2014). This tool is a browser port of the reference Python implementation (vaderSentiment 3.3.2).
